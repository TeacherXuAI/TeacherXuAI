### [Google Antigravity 中文汉化补丁](https://github.com/TeacherXuAI/antigravity-zh-cn)

- **当前支持：** macOS / Antigravity Desktop 2.22.0，Apple Silicon 已实测。
- **当前范围：** 通用、应用、外观、模型与用量四个设置页及部分导航；社区预览版，非官方。
- **[查看项目与安装说明](https://github.com/TeacherXuAI/antigravity-zh-cn) · [下载预览版](https://github.com/TeacherXuAI/antigravity-zh-cn/releases) · [反馈问题](https://github.com/TeacherXuAI/antigravity-zh-cn/issues)**
